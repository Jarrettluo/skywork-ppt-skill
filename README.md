# Skywork Ppt

> Use this skill when the user wants to: (1) generate a PPT from a topic — trigger on '/ppt_write', 'generate a PPT', 'create a presentation about X', 'help me generate a PPT'; OR (2) use an existing .pptx as a style template to generate a new presentation on a different topic — trigger on 'use this template', 'imitate this PPT', 'imitate this style'; OR (3) perform local operations on an existing .pptx file without backend — trigger on 'delete slide N', 'reorder slides', 'rearrange PPT', 'merge p…

## 安装

将本仓库放到 OpenClaw 技能目录即可使用：

```bash
git clone <本仓库地址> ~/.openclaw/workspace/skills/skywork-ppt-skill
# 或放入 ~/.openclaw/skills/
```

## 配置

如需 API Key、邮箱授权码等配置，请参考 `SKILL.md` 中的说明，通过环境变量或本地 `.env` 文件设置（**不要提交到仓库**）。
